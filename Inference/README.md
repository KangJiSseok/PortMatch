# Inference

추론/런타임 용도로 사용하며, 신규 팀원이 빠르게 구조를 이해할 수 있도록 정리했습니다.

## 폴더 구조

- `web/`
  - 추론 서버에서 사용하는 API, 스키마, 도메인 로직, 서비스 코드.
  - `web/api/` : 라우터/엔드포인트 정의.
  - `web/domain/` : 비즈니스 로직과 도메인 모델.
  - `web/schemas/` : 요청/응답 스키마(예: Pydantic 모델).
  - `web/services/` : 외부 연동/서비스 레이어.
  - `web/config/` : 설정 로딩/환경 변수 관리.
- `laboratory/`
  - 실험용 스크립트, 프로토타입, 테스트 코드.
  - 개발자별 폴더를 만들어 개별 실험을 진행합니다. (예: `laboratory/kangjiseok/`)
- `docs_cache/`
  - 문서 처리 과정에서 생성되는 캐시/중간 산출물.
- `runs/`
  - 실행 결과(검출/추론 결과, 로그 등) 저장.
- `temp_files/`
  - 처리 중 임시 파일 저장.

## 파일

- `main.py`
  - 추론 워크플로우 실행 진입점.

## 참고

- `.venv/`, `.idea/`는 개발 환경별 설정으로, 프로젝트 핵심 구조에 포함되지 않습니다.
- 빈 폴더 추적을 위해 각 폴더에 `.gitkeep`을 사용합니다.
