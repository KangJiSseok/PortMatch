## 📅 TIL (Today I Learned) - 2026.01.22 (목)

### 1. 오늘의 목표

- 로그인 기능의 백엔드 API 연동 완료 및 Zustand를 활용한 전역 상태 관리 도입

### 2. 진행 내용

- **백엔드 API 연동 성공**
  - `useLogin` 훅을 통해 실제 서버 데이터와 통신하며 사용자 인증 로직을 완성함.
  - `APPLICANT`와 `COMPANY` 역할을 구분하는 `expectedRole` 페이로드를 전송하여 다중 권한 로그인 체계를 구축함.
- **Zustand 기반 전역 상태 관리**
  - 로그인 성공 시 발급받는 토큰 및 사용자 정보를 전역에서 관리할 수 있도록 Zustand 스토어를 연결함.
  - 새로고침 시에도 인증 상태를 유지하거나, 애플리케이션 전역에서 접근 가능한 `useAuth` 구조를 마련함.
- **에러 핸들링 고도화**
  - `axios.isAxiosError`를 사용하여 서버에서 전달하는 구체적인 에러 메시지(`serverMessage`)와 상세 검증 로직(`validationDetail`)을 사용자에게 정확히 전달하도록 설계함.
  - '로그인 실패'라는 단순한 메시지 대신, 서버 피드백을 우선시하는 사용자 친화적 에러 가이드 구현.

### 3. 배운 점 (Insights)

- **전역 상태 관리의 편리함**
  - Props Drilling 없이 로그인 정보를 관리할 수 있는 Zustand의 간결함을 체감했으며, 이는 추후 마이페이지나 이력서 관리 기능에서 유기적으로 활용될 것을 기대함.
- **서버-클라이언트 에러 동기화**
  - 서버의 응답 객체 구조(`error.response.data`)를 분석하여 클라이언트 UI에 적절히 매핑하는 과정을 통해, 백엔드와 프론트엔드 간의 데이터 규격(API Spec) 통일이 얼마나 중요한지 학습함.

### 4. 다음 단계

- **인증 기반 접근 제어:** 로그인되지 않은 사용자가 마이페이지나 이력서 상세 페이지에 접근할 수 없도록 하는 Private Route 구현.
- **API 호출 공통화:** Axios 인터셉터를 설정하여 모든 요청 시 Header에 Access Token을 자동으로 포함시키는 로직 구축.
