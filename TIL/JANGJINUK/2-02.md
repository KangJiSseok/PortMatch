### 1. 오늘의 목표

### 2. 진행 내용

- **실시간 일정 동기화 시스템 (`ScheduleManagementPage`)**
  - **Firestore Real-time Listeners**: `onSnapshot`을 사용하여 팀원이 시간을 선택하면 모든 접속자의 화면에 즉시 반영되는 실시간 데이터 파이프라인 구축.
  - **인터랙티브 타임 그리드**: 마우스 드래그(`isDragging`)를 통한 연속 시간대 선택/해제 기능으로 사용자 편의성 극대화.
- **지능형 스케줄 분석 알고리즘**
  - **TOP 3 추천**: `useMemo`를 활용해 전체 투표 데이터를 분석하고, 가장 많은 인원이 참여 가능한 최적의 시간대 3곳을 자동으로 추출하는 로직 구현.
  - **참여자 필터링**: 특정 참여자 클릭 시 해당 인원이 선택한 시간대만 하이라이트하여 보여주는 '개별 확인 모드' 추가.
- **견고한 예외 처리 및 UX 설계**
  - **중복 방지**: 동일 브라우저 내 이름 중복 체크 및 필수 항목 누락 시 해당 섹션으로 자동 스크롤되는 유효성 검사 로직 강화.
  - **상태 관리**: `Framer Motion`과 커스텀 모달 시스템을 결합하여 성공, 오류, 초기화 확인 등 직관적인 피드백 제공.

### 3. 배운 점 (Insights)

- **NoSQL 데이터 구조화의 묘미**
  - 24시간 × 7일의 방대한 타임슬롯 데이터를 효율적으로 관리하기 위해 `id: '요일-시간'` 구조의 배열로 정규화하여 Firestore 저장 용량과 속도를 최적화함.
- **선언적 UI와 상태 동기화**
  - "데이터가 변하면 UI는 저절로 그려진다"는 리액트의 원칙을 `onSnapshot`과 연결하여, 복잡한 비동기 로직 없이도 강력한 협업 도구를 만들 수 있음을 체감함.
- **사용자 경험을 결정짓는 디테일**
  - 링크 복사 기능, 드래그 모드(`select` / `deselect`), 초기화 방지 모달 등 실제 사용자가 느낄 불편함을 미리 예측하고 해결하는 설계 능력을 배양함.
