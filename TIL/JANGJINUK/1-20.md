## 📅 TIL (Today I Learned) - 2026.01.20 (화)

### 1. 오늘의 목표
* 이력서 상세 조회 및 실시간 편집 시스템 구현 (Resume Management System)

### 2. 진행 내용
* **복합 상태(Complex State) 관리 및 UI 동기화**
    * `useState`를 활용해 조회 모드와 편집 모드를 전환하는 `isEditing` 로직 구현.
    * 편집 모드 시 전역적인 시각적 피드백(배경색 변경, 하단 알림 바 노출)을 제공하여 UX 향상.
* **사용자 편의를 위한 입력 포맷터(Formatter) 개발**
    * `formatPhoneNumber`: 전화번호 입력 시 자동으로 하이픈(-)을 삽입하는 정규식 로직 적용.
    * `formatPeriod`: 기간 입력 시 `YYYY.MM - YYYY.MM` 형태로 자동 변환되는 포맷터 구현.
* **동적 리스트 관리 및 CRUD 인터페이스**
    * 경력(Experience), 학력(Education) 섹션의 동적 추가/삭제 기능을 구현하여 사용자 맞춤형 이력서 작성이 가능하도록 설계.
    * `AnimatePresence`와 `motion`을 활용해 드롭다운 리스트(이력서/포트폴리오/자기소개 선택)의 부드러운 전환 효과 구현.
* **파일 시스템 연동 및 데이터 매칭**
    * `useRef`를 이용한 커스텀 파일 업로드 버튼 구현 및 업로드 시 포트폴리오 리스트에 즉시 반영되는 로직 작성.
    * 선택된 ID 값에 따라 전체 데이터 배열에서 해당 객체를 찾아 매칭하는 `find` 로직 구성.

### 3. 배운 점 (Insights)
* **데이터 모델링의 중요성**
    * 이력서, 자기소개서, 포트폴리오가 각각 독립된 데이터셋을 가지면서도 ID 참조를 통해 유기적으로 연결되는 구조를 설계하며 관계형 데이터의 처리 방식을 익힘. 
* **UX 중심의 조건부 렌더링**
    * 단순히 `input` 필드를 노출하는 것을 넘어, 편집 중일 때만 추가/삭제 버튼이 나타나게 하거나 텍스트 영역이 `textarea`로 변환되는 등 상황에 맞는 최적의 UI 제공 방식을 학습함.
* **코드 가독성을 위한 컴포넌트 추상화**
    * 공통 카드 레이아웃인 `SectionCard`를 분리하여 반복되는 UI 코드를 줄이고 유지보수성을 높임.
