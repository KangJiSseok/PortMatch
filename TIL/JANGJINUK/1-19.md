## 📅 TIL (Today I Learned) - 2026.01.19 (월)

### 1. 오늘의 목표

- Framer Motion을 활용한 고도화된 스크롤 기반 애니메이션(AOS) 인터랙션 구현

### 2. 진행 내용

- **스크롤 진행도 기반 상태 제어**
  - `useScroll`과 `useMotionValueEvent`를 사용해 전체 페이지의 스크롤 위치(`scrollYProgress`)를 실시간으로 추적함.
  - 특정 스크롤 임계점(0.3, 0.75 등)에 도달할 때마다 `activeSection` 상태를 업데이트하여 현재 활성화된 섹션을 동적으로 관리함.
- **`useTransform`을 이용한 수치 보간(Interpolation)**
  - 스크롤 위치(0~1)를 투명도(`opacity`), 좌표(`x`, `y`) 등의 속성값으로 매핑하여 정밀한 트랜지션을 구현함.
  - 섹션 1의 상/하단 이미지가 좌우로 분할되며 사라지는(x축 이동) 시각적 효과를 설계함.
- **사용자 편의 기능 구현**
  - 인디케이터 클릭 시 부드럽게 목표 섹션으로 이동하는 `handleScrollToSection` 함수를 작성함.
  - `layout` prop과 `whileHover`를 사용하여 섹션 호버 시 영역이 가변적으로 확장되는 인터랙티브 레이아웃을 구성함.

### 3. 배운 점 (Insights)

- **정밀한 애니메이션 타이밍 설계**
  - 라이브러리의 기본 설정에 의존하지 않고, 직접 스크롤 진행도를 수치화하여 애니메이션의 시작과 끝 지점을 세밀하게 조정하는 방법을 익힘.
- **서비스 정체성(PORTMATCH) 시각화**
  - '입체 역량 분석'이라는 서비스 키워드에 맞춰 `mix-blend-difference`와 고대비 레이아웃을 사용함으로써 인트로 페이지의 몰입감을 극대화함.
- **비즈니스 로직과의 연결**
  - 애니메이션뿐만 아니라 `localStorage`를 이용해 구직자(applicant)와 기업(company) 역할을 구분하여 리다이렉트하는 로그인 흐름을 연동함.
