## 📅 TIL (Today I Learned) - 2026.01.23 (금)

### 1. 오늘의 목표

- 포트폴리오 CRUD 및 AI 분석 API 연동을 통한 데이터 흐름 완성

### 2. 진행 내용

- **인증 기반 API 모듈화 (`portfolioApi.ts`)**
  - `localStorage`에 저장된 Zustand 상태(`auth-storage`)에서 JWT 토큰을 추출하여 모든 요청의 `Authorization` 헤더에 자동 포함하는 로직 구현.
  - `fetch` API를 활용하여 포트폴리오 목록 조회, 업로드, 삭제, 분석 요청 등 총 6개의 핵심 엔드포인트 연동.
- **FormData를 활용한 멀티파트 파일 업로드**
  - PDF 등 포트폴리오 파일 전송을 위해 `FormData` 객체를 생성하고, 파일 업로드 시에만 헤더의 `Content-Type`을 브라우저가 자동 설정하도록 처리하는 세밀한 핸들링 적용.
- **Vite Proxy 설정을 통한 CORS 및 통신 안정화**
  - `vite.config.ts`에서 프록시 타겟을 `localhost` 대신 `127.0.0.1`로 명시하여 네트워크 통신 지연 및 에러 방지.
  - 백엔드 서버(Spring Boot, 8080 포트)와의 API 경로를 일치시켜 개발 환경에서의 연동성 확보.
- **데이터 타입 정의 (`portfolio.ts`)**
  - 서버 응답 규격에 맞춘 `PortfolioResponse`, `AnalysisResponse` 인터페이스 정의.
  - 특히 AI 분석 결과 데이터(프로젝트명, 문제점, 해결 방안, 스택 등)를 담는 구조화된 타입 설계.

### 3. 배운 점 (Insights)

- **상태 관리와 API의 결합**
  - Zustand의 스토리지 구조를 파악하여 API 호출 시마다 최신 토큰을 안전하게 가져오는 방법을 익힘.
- **네트워크 트러블슈팅**
  - 로컬 개발 환경에서 발생할 수 있는 호스트 이름 해석 문제(`localhost` vs `127.0.0.1`)를 프록시 설정을 통해 해결하며 통신 안정성의 중요성을 체감함.
- **비동기 흐름 제어**
  - 파일 업로드 후 즉시 목록을 갱신하거나, 분석 요청 후 결과를 다시 가져오는 일련의 비동기 흐름을 정의하며 완성도 있는 데이터 파이프라인 구축.
