## 📅 TIL (Today I Learned) - 2026.01.30 (금)

### 1. 오늘의 목표

- Firebase Realtime Database를 활용한 실시간 메신저 기능 구현 및 데이터 동기화 로직 구축

---

### 2. 진행 내용

- **Firebase 프로젝트 연동 및 환경 설정**
  - Firebase SDK를 설치하고 `apiKey`, `databaseURL` 등 프로젝트 설정 값을 React 환경 변수와 연동함.
  - 실시간 통신을 위해 `getDatabase`, `ref`, `onValue`, `push` 등의 핵심 API를 모듈화함.
- **실시간 메시징 로직 구현**
  - **메시지 전송**: `push()`를 사용하여 고유 키를 생성하고, `set()`을 통해 메시지 객체(sender, text, timestamp 등)를 저장함.
  - **실시간 수신**: `onValue()` 리스너를 통해 데이터베이스의 변경 사항을 실시간으로 감지하고, 메시지 리스트를 즉시 업데이트함.
- **메신저 UI 구성**
  - Tailwind CSS를 활용해 구직자와 기업 간의 대화창 레이아웃을 구성함.
  - 스크롤 하단 자동 고정 로직 및 메시지 시간 포맷팅 처리를 추가함.

---

### 3. 배운 점 (Insights)

- **WebSocket 대안으로서의 Firebase**
  - 별도의 백엔드 소켓 서버 구축 없이도 저지연(Low-latency) 실시간 통신을 구현할 수 있는 서버리스의 강력함을 체감함.
- **NoSQL 기반 실시간 데이터 트리 구조**
  - 정형화된 RDBMS와 달리 트리 형태의 JSON 구조로 대화 내역을 설계하며, 실시간 동기화 효율을 높이기 위한 데이터 구조화의 중요성을 배움.
- **Optimistic UI와 실시간성**
  - 메시지 전송 시 로컬 상태를 먼저 업데이트하고 서버 응답을 기다리는 '낙관적 업데이트' 방식과 Firebase의 자동 동기화 기능을 비교하며 사용자 경험을 고민함.
