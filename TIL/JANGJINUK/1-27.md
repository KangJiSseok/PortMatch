## 📅 TIL (Today I Learned) - 2026.01.27 (화)

### 1. 오늘의 목표

- 사용자의 편의성 증진을 위한 면접 질문 리스트 및 템플릿 관리 페이지(`InterviewTemplatePage`) 구현

---

### 2. 진행 내용

- **인터랙티브 면접 템플릿 시스템 구축**
  - **고도화된 리스트 관리**: 인터뷰 주제(Category)별로 질문을 그룹화하고, 전체 템플릿의 생성, 수정, 삭제 및 검색 기능을 구현함.
  - **드래그 앤 드롭(Drag & Drop) UI**: `Framer Motion`의 `Reorder` 및 `useDragControls`를 활용하여 주제 순서와 내부 질문 순서를 직관적으로 변경할 수 있도록 처리함.
  - **역할 기반 UI 대응**: 사용자의 역할(개인/기업)에 따라 카테고리 기본값과 용어를 다르게 노출하도록 설계함.

- **사용자 경험(UX) 안정성 강화**
  - **데이터 유실 방지**: `react-router-dom`의 `useBlocker`와 브라우저 `beforeunload` 이벤트를 사용하여 작성 중 페이지 이탈 시 경고 모달을 띄우는 로직을 구현함.
  - **세밀한 예외 처리**: 필수 항목 누락 시 자동 스크롤(`scrollToSection`) 기능과 토스트 메시지를 통한 즉각적인 피드백 제공.
  - **실시간 답변 작성**: 템플릿 상세 보기 모달에서 질문별 답변을 입력하고 `localStorage`에 즉시 반영하는 로직 구축.

---

### 3. 배운 점 (Insights)

- **복합 드래그 레이아웃 제어**
  - 중첩된 `Reorder.Group` 관리 시 `layout="position"`과 `dragListener={false}`를 조합해 정밀한 드래그 제어 기법을 익힘.
- **입력 유효성 검사 및 자동 포커스**
  - 주제 추가 시 중복 체크와 글자 수 제한으로 데이터 정합성을 유지하고, 오류 발생 시 시선을 유도하는 UI 가이드의 중요성을 체감함.
- **사용자 친화적 네비게이션**
  - 폼 작성 시 의도치 않은 이탈을 막는 `useBlocker` 라이프사이클을 적용해 서비스 안정성을 높임.
