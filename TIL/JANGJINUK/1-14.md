## 📅 TIL (Today I Learned) - 2026.01.14 (수)

### 1. 오늘의 목표
* 피드백을 반영한 우선순위 매트릭스 재설계
* 서비스의 뼈대가 되는 요구사항 명세서 작성 완료

### 2. 진행 내용
* **우선순위 매트릭스 고도화 (의존성 고려)**
    * **피드백 반영:** 기존 매트릭스가 사용자 파이프라인 중심이라 개발 의존성이 간과되었다는 점을 파악함.
    * **수정 방향:** 기능 간의 선후 관계를 고려하여 업무 번호를 부여하고, 기술적 구현 순서에 맞게 재배치함.
* **요구사항 명세서(Specification) 완성**
    * 프로젝트 기획 의도부터 주요 기능(B2C, B2B, Admin), 개발 환경(Java, Python, React 등), 상세 요구사항(CRUD 및 기술 속성 기반 분류)을 문서화함.
    * 구체적인 기능 정의를 통해 팀원 간의 개발 범위를 명확히 함.

### 3. 배운 점 (Insights)
* **기획의 흐름 vs 개발의 순서**
    * 사용자가 경험하는 순서와 실제로 코드가 작성되는 순서는 다르며, 데이터 수집(파싱, 크롤링)이 선행되어야 후속 기능 개발이 가능하다는 것을 깨달음.
* **문서화의 가치**
    * 명세서를 정리하면서 막연했던 기능들이 구체적인 '구현 단위'로 쪼개지는 것을 확인했으며, 이는 향후 DB 설계와 API 작성의 기준점이 됨.

### 4. 다음 단계
