# 📝 [TIL] 2026-01-30  
## 원티드 API 분석 및 기술 스택 데이터 마스터 확보

채용 공고 분석의 핵심인 **기술 스택 데이터**를 확보하기 위해  
원티드(Wanted) API 구조를 분석했다.  
단순 크롤링을 넘어 **API 응답 구조와 태그 시스템**을 이해하는 데 집중했다.

---

## 1. 구현 내용: 기술 스택 마스터 데이터 수집

- **데이터 출처**
  - 원티드 내부 API: `/api/v4/skills`

- **핵심 성과**
  - 총 **7,955개**의 기술·역량 데이터 확보
  - 브라우저 개발자 도구(Network 탭)를 활용한  
    실질적인 데이터 추출 방식 습득

---

## 2. 주요 트러블슈팅

### 🚨 Issue 1. 단순 HTTP 요청 차단 (403 / 404)

**현상**  
- `requests` 라이브러리로 API 호출 시 403 또는 404 응답

**원인**  
- 브라우저 세션 기반 인증
- 원티드의 강화된 API 접근 제어

**해결**  
- 브라우저 Network 탭에서 실제 호출되는 API 확인
- 정상 인증된 상태에서 전달되는 JSON 응답을 직접 추출
- 추출한 데이터를 로컬 파일로 저장하여 활용

---

### 🚨 Issue 2. 기술 스택과 직무 데이터 혼동

**현상**  
- 수집한 데이터에 `서버 개발자`, `웹 디자이너` 등 직무명이 포함됨  
- 기대했던 Java, React 같은 기술명이 아님

**원인**  
- 원티드 태그 시스템이 단일 구조가 아님
  - 직무(Job)
  - 기술(Skill)
  - 혜택/역량 등으로 분리됨

**해결**  
- 기술 스택 전용 API 엔드포인트 재탐색
- 개발 기술(Java, React 등)이 포함된  
  **통합 스킬 마스터 데이터 확보 성공**

---

## 3. 핵심 개념 정리

### 왜 기술 스택에 비개발 키워드가 섞여 있을까?

원티드의 스킬 시스템은 단순한 프로그래밍 기술이 아니라  
**직무 전반의 역량을 포괄적으로 관리**하기 때문이다.

- **협업 도구**
  - Slack, Jira 등 개발 환경 필수 도구 포함
- **도메인 지식**
  - B2B, 금융, 회계 등 산업별 전문 역량
- **데이터 통합 전략**
  - 개발·마케팅·영업 등 전 직군의 역량을  
    하나의 마스터 테이블에서 관리
  - 데이터 재사용성과 확장성 극대화
