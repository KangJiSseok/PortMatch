## 💡 오늘 배운 것 – JPA 개념 정리

### JPA 기본 개념 정리

- **개념 설명**
    
    JPA는 DB 테이블 중심이 아니라 객체(Entity) 중심으로 설계하는 ORM 기술이다.
    
    SQL을 직접 다루기보다, 객체의 상태 변화와 관계를 기준으로 데이터를 관리한다.
    
- **핵심 포인트**
    - JPA는 Entity ↔ Table 매핑만 책임진다
    - DTO ↔ Entity 매핑은 JPA 역할이 아니다
    - 객체 중심 설계란 DB 구조를 쉽게 바꾸는 것이 아니라
        
        DB 변경이 비즈니스 로직까지 퍼지지 않게 막는 것
        
    - `ddl-auto`는 개발 편의 기능일 뿐, 설계의 핵심은 아니다
- **이해한 흐름**
    
    ```
    Controller →DTO
    Service → 비즈니스 로직+Entity 사용
    Repository →Entity ↔DB
    
    ```
