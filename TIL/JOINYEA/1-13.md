# 📘 TIL – WebRTC 기초 개념

## 💡 오늘 배운 것

- WebRTC는 브라우저 간 실시간 통신을 위한 기술
- 화상·음성뿐 아니라 DataChannel을 통한 데이터 전송도 가능
- 기본 구조는 시그널링 서버 + P2P 통신
- 초저지연이 필요한 서비스에 적합

## 🧐 정리하며 헷갈렸던 점

- WebRTC는 화상 채팅 전용 기술이 아님
    
    → 실시간 데이터 통신 기술로도 많이 사용됨
