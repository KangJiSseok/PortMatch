# 📘 TIL – 외부 채용 API 연동 & RestTemplate 구조 이해

## 💡 오늘 배운 것

- 채용 공고를 가져오기 위해 **사람인 Open API**를 활용할 수 있다.
- 외부 API 호출은 **Spring에서 RestTemplate**으로 간단히 구현 가능하다.
- 단순 GET 요청이라면 `getForObject()` 만으로도 충분하다.
- API 응답(JSON)을 받아 **ObjectMapper로 파싱 → DTO(Entity)로 변환**하는 구조가 일반적이다.

## 🧱 API 연동 기본 구조

- Controller → Service → (RestTemplate로 외부 API 호출)
- DB 저장이 필요 없다면 **DAO / ERD 없이도 구현 가능**
- 스크랩(관심 공고) 기능이 필요해지면 그때 ERD와 DB를 설계해도 된다.

## ⚙️ Config의 역할

- `@Configuration`에서 `RestTemplate`을 Bean으로 등록하면  
  → 여러 Service에서 **재사용**, 공통 설정(timeout, header 등) 관리 가능
- 하지만 단순한 개인 프로젝트라면  
  → Service 내부에서 `new RestTemplate()`로 바로 써도 문제 없음
