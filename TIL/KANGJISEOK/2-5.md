# 백 프론트 배포환경 분리

### 백엔드가 인프라 구성하면서 에러가 나면 배포서버 자체가 문제 생기면서 프론트가 서버를 이용하지 못함.

compose 파일을 2개 만들어서 1개는 prod, 1개는 dev로 만들자.
프론트는 항상 prod를 바라보게 만들고 백엔드는 dev에서 작업하다가 prod로 주기적으로 push.


# CI 최적화

### 매번 CI 돌때마다 모든 서버를 이미지화 시켜서 올리면서 시간이 오래걸리는 문제 발생.

CI에서 변경파일만 탐지해서 해당 파일만 이미지화 시켜서 올리기.

### 도커는 이미지를 빌드시킬때 tag가 바뀌지 않으면 똑같은 이미지로 인지해서 해당 이미지는 빌드시키지 않음.
### 컴포즈 내에서 브릿지를 선언 안해서 컴포즈로 빌드 할때 컨테이너가 서로 다른 브릿지에 속하는 문제 발생.

compose에 브릿지 선언하고 묶어서 해결
