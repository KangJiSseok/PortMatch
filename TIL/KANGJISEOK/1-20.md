# 2026-01-20 TIL

## 문제 상황
- Spring에서 FastAPI로 `POST /api/parse` 요청 시 422 또는 400이 발생했고, FastAPI 로그에는 `Invalid HTTP request` 경고가 출력됐다.
- FastAPI에서는 `s3_url`이 비었다고 판단하여 요청을 처리하지 못했다.

## 원인 분석
- Spring의 HTTP 클라이언트가 **HTTP/2(h2c) 업그레이드 헤더**(`Upgrade: h2c`, `HTTP2-Settings`)를 자동으로 붙여 전송했다.
- FastAPI(Uvicorn)는 **h2c 업그레이드를 지원하지 않기 때문에** 요청을 무효로 처리했고, 그 결과 body를 읽지 못해 `s3_url`이 비어 있는 것으로 판단했다.

## 해결 과정
- Spring에서 FastAPI로 보내는 HTTP 클라이언트를 **HTTP/1.1만 사용하는 방식으로 고정**했다.
  - `SimpleClientHttpRequestFactory`를 사용해 h2c 업그레이드 헤더를 제거.

## 핵심 요약
- 문제의 본질은 **HTTP/2 h2c 업그레이드 실패로 FastAPI가 요청 body를 버린 것**.
- 해결은 **Spring 클라이언트를 HTTP/1.1 고정**으로 변경하는 것.
