## 2) Navbar 때문에 생긴 문제 & 해결

### 문제

- sticky 박스와 섹션 이동이 **navbar에 가려짐**
- 탭/바로가기 클릭하면 원하는 위치보다 위에서 멈춰서 내용이 안 보임

### 해결

- Navbar 높이를 `useLayoutEffect`로 측정해서 `OFFSET` 계산
- 스크롤 가림 방지 2가지 적용
  1. `document.documentElement.style.scrollPaddingTop = OFFSET`
  2. 섹션 카드에 `scrollMarginTop: OFFSET` 적용
- 커스텀 스크롤 이동 함수
  - `getBoundingClientRect().top + window.scrollY - OFFSET`로 위치 보정

## 3) React Hook 관련 오류 해결 (중요)

### 발생했던 에러

- `Rendered more hooks than during the previous render`
- 원인: **조건부 return 전에 hook이 추가로 실행되면서 훅 호출 순서가 바뀜**

### 해결

- 모든 hook은 컴포넌트 상단에서만 호출되게 정리
- `if (loading) return ...` 같은 early return은 **hook 선언 이후**, 추가 hook 없이 처리

- 현재 mock은 localStorage 기반이라 동기 처리지만,
- UX적으로는 “클릭 시 바로 UI 변경 → 저장 처리” 흐름(옵티미스틱)으로 개선 가능
- 스크랩 버튼 위치는 공고 요약 카드 상단 영역에 배치하는 것이 사람인 느낌과 잘 맞았음

## 배운 점 / 회고

- sticky + 섹션 이동 UI에서는 `scrollMarginTop`/`scrollPaddingTop`이 **진짜 핵심**
- Hook 순서 오류는 한 번 터지면 화면이 아예 깨지므로
  “hook은 상단에서만, 조건부 return 아래에 hook 추가 금지” 규칙을 확실히 지켜야 함
- 타입스크립트 문법은 `.tsx`에서만 안전하게 사용
