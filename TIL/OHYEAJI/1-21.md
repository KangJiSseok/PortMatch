## 1) 개인 마이페이지 UI 개선

### 작업 내용

- 레이아웃/카드 UI 정리
    - 섹션 구성(카드/리스트) 간격 및 정렬 통일
    - 버튼 배치 개선(주요 행동이 눈에 들어오게)
- 상태 UI 개선
    - 로딩 시 Skeleton 적용
    - 에러 시 재시도 버튼 포함한 Error UI 구성
    - 빈 상태(EmptyHint) 문구/표현 통일
- 컴포넌트 재사용성 강화

### 느낀 점

- 같은 기능이라도 “로딩/에러/빈 상태”가 깔끔하면 페이지 완성도가 확 올라간다.
- UI는 결국 “사용자 흐름(동선)”이 정리돼야 만족도가 생김.

## 2) 기업 마이페이지(CorporateMyPage) 구현

### 목표

기업 담당자가 공고/면접을 한 화면에서 빠르게 확인하고, 필요한 관리 페이지로 바로 이동할 수 있게 만들기.

### 구현 내용

- **헤더**
    - 기업명/담당자/이메일 노출
    - 공고 관리 / 공고 등록 CTA 배치
- **관리 바로가기(공고/면접 카드)**
    - 공고 리스트: 최대 N개(현재 4개) 프리뷰 표시
    - 면접 리스트: 예정된 면접 프리뷰 표시 + **지원자별 이력서 보기 버튼** 제공
    - 클릭 동작 분리
        - row 클릭 → 면접 관리 페이지 이동
        - “이력서 보기” 버튼 클릭 → 해당 지원자 이력서 페이지 이동 (stopPropagation 처리)
- **캘린더 섹션**
    - 월 단위 캘린더 렌더링
    - 날짜별 면접 일정 건수 표시
    - 선택한 날짜의 상세 일정 패널 제공
    - 일정 항목에서 이력서 보기 버튼 제공
- **추가 UX 포인트**
    - 면접 “전체보기 모달”은 삭제
    - 대신 **면접 리스트(면접 관리 페이지)로 이동 CTA를 더 눈에 띄게 배치**
    - 로딩/에러/빈 상태 UI 통일

### 메모

- 면접방 입장(실제 인터뷰 룸 진입)은 보통 **면접 리스트 페이지에서** “입장” 버튼으로 처리하는 게 자연스럽다.
    - 대시보드에서는 “요약 + 빠른 이동”이 더 역할에 맞음.

## 3) Docker 설치 & 기초 학습

### 오늘 한 것

- Docker 설치
- Docker Desktop 실행/환경 확인
- 기본 개념 학습(진짜 기초만)

### 정리한 개념

- **Image**: 실행 환경이 패키징된 템플릿(설계도)
- **Container**: 이미지를 실행한 실제 프로세스(실행 중인 인스턴스)
- **Dockerfile**: 이미지를 만드는 레시피
- **docker-compose**: 여러 컨테이너(DB/서버 등)를 한 번에 띄우는 설정 파일
- **Volume**: 컨테이너 삭제해도 데이터 유지하는 저장소
- **Port Mapping**: 컨테이너 내부 포트를 로컬 포트에 연결(예: 3000:3000)

### 다음에 해볼 것

- `docker run`으로 간단 컨테이너 띄우기 (nginx, postgres 같은 걸로)
- `docker-compose.yml`로 DB + 서버 같이 띄우는 흐름 익히기
- 프로젝트에 적용할 때 “개발/배포 환경 차이”도 같이 정리하기
