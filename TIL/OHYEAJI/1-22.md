### 2) 지원서 작성 페이지(JobApplyPage) 신규 구현

**목표:** 공고 상세 → 지원하기 → 지원서 작성/제출까지 한 흐름으로 연결

- 공고 상세의 **지원하기 버튼 클릭 시 `/job-posts/:id/apply` 이동** 흐름 추가
- `JobApplyPage`에서 **이력서 선택 + 지원서 제출** 구현
- 페이지 진입 시 `window.scrollTo({ top: 0 })`로 **자동 상단 이동** 처리

**주요 기능**

- 공고 요약 영역 표시(회사명/공고명/마감일/D-day)
- 이력서 목록 렌더링 + 선택 UI
- 제출 요약 패널(선택한 이력서, 지원 가능 여부)
- 지원 가능 여부 처리
  - 공고 `status` / `마감일` 기반으로 제출 버튼 활성/비활성
- 제출 처리(임시 저장)
  - 제출 시 `localStorage(jobApplications)`에 지원 이력 저장
  - 제출 완료 모달(공고로 돌아가기 / 마이페이지 이동)

**변경 파일**

- `src/pages/JobApplyPage.tsx` (신규)
- `src/App.tsx` : `/job-posts/:id/apply` 라우트 추가 + `ProtectedRoute` 적용
- (필요 시) 공고 상세 페이지에서 지원하기 버튼 라우팅 연결

### 3) 고정폭 레이아웃 통일 + 가로 스크롤 흰 화면 문제 해결

**문제:** 창이 줄어들 때 반응형으로 레이아웃이 깨지거나, 가로 스크롤 시 오른쪽이 흰 화면으로 보임

**해결:** 내부 래퍼 스크롤(`overflow-x-auto`) 방식 대신 **문서(body)가 넓어지게(min-w)** 통일

- 각 페이지 root에 `min-w-[1280px]` 적용
- 내부 컨테이너는 `w-[1280px]` 고정 + `mx-auto` 유지
- 스켈레톤/에러/빈화면(notfound 포함)도 동일 규칙 적용해서 **상태 UI에서도 스크롤 동작 일관성 유지**

**적용 페이지**

- MyPage (개인) / CorporateMyPage (기업)
- InterviewListPage / CorporateInterviewListPage
- InterviewLobbyPage / InterviewPage
- JobApplyPage
- JobPostDetailPage
- 각 페이지의 loading/error/notfound 상태 UI 포함
