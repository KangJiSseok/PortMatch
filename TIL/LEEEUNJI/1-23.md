## 2. 401 에러가 발생한 이유와 개발 단계에서의 대응 전략

### 발생 상황

- `/company/recommended-candidates` 요청 시
- Network 탭에서 401 Unauthorized 에러 발생

### 확인한 내용

- Request Headers에 `Authorization` 없음
- localStorage에 accessToken 존재하지 않음
- 현재는 개발용 역할 토글로  
  `GUEST / APPLICANT / COMPANY`만 모킹 중

### 원인 정리

- 백엔드 연동 전인데
- **인증이 필요한 실제 API를 호출하고 있었음**

> 이 상황에서 401은  
> 버그가 아니라 **정상적인 서버 반응**이었다.

---

### 선택한 해결 방식

> 개발 중에는  
> **API 요청 자체를 보내지 않는다**

### 적용 방법

- React Query의 `enabled` 옵션 사용

```ts
useQuery({
  queryKey: [...],
  queryFn: fetchFn,
  enabled: !devMode,
});
```
- 페이지에서는 개발 환경일 때 MOCK 데이터만 사용

```ts
const candidates = devMode ? MOCK_CANDIDATES : apiData;
```
### 결과
- 개발 모드에서는 Network 요청 자체가 나가지 않음 또한 401 에러도 발생하지 않음 덕분에 UI 테스트에만 집중 가능
> 에러를 처리하는 것보다
> 지금 단계에 맞는 호출을 설계하는 게 더 중요했다
