## 1️. RecommendCompanyPage API 연동 구조 정리

#### 연동 대상 API
GET /api/portfolios/{portfolioId}/recommendations/companies


#### 구조적으로 중요한 포인트
- `portfolioId`는 **URL param**으로 전달하는 것이 가장 명확
- API 연동은 역할별로 분리하는 것이 정석
  - `src/api` : axios 요청 함수
  - `src/hooks` : React Query (`useQuery`)
  - `src/types` : API 응답 타입
  - `page` : UI + 상태(로딩/에러/빈 상태)

## 2️. Network 탭에 아무것도 안 뜨던 진짜 이유
처음에는 쿠키 / CORS / 인증 문제를 의심했지만 원인은 훨씬 단순했다.

- 추천 기업 페이지에서 API 호출 자체가 존재하지 않음
- 그래서 Network 탭에 아무것도 안 찍히는 게 정상


## 3. 로딩 / 에러 문구도 UI의 일부다
로딩 문구, 에러 문구, 필수 파라미터 누락시 안내 문구 작성
