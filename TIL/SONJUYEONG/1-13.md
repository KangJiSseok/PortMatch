# 🗒️ TIL – Jira 기본 개념 & 사용 흐름 정리

## 📌 Jira란?
애자일 방식(Agile Methodology)으로 프로젝트를 관리하기 위한 협업 도구.  
팀이 해야 할 일을 쪼개고, 우선순위를 정하고, 시각화해 진행 상황을 관리한다.

---

## 🔷 Jira 핵심 개념 정리

### 🧩 1. 에픽(Epic)
- **큰 주제/기능 단위**
- 프로젝트 전체 목표를 구성하는 **상위 개념**
- 예) 로그인 기능, NFC 결제 기능, 관리자 페이지 구축

> 에픽은 '큰 덩어리를 의미', 이후 작은 작업 단위로 쪼개진다

---

### 📋 2. 백로그(Backlog)
- **해야 할 모든 작업 목록**
- 에픽을 작은 단위로 나눈 것 = 스토리/태스크로 채워짐
- 아직 할지 말지, 언제 할지 정해지지 않은 **작업 저장소**

> 백로그는 “언젠가 해야 하거나 검토해야 할 일들의 냉장고”

---

### 🚧 3. 스프린트(Sprint)
- **정해진 기간 동안 수행할 작업 묶음**
- 보통 1~2주로 설정
- 백로그 중 이번 기간에 수행할 일을 선택 → 스프린트에 넣음

> 스프린트는 “계획 → 수행 → 회고”라는 주기적 반복 구조

---

### 🎯 4. 스토리 포인트(Story Point)
- 작업의 **난이도와 소요 실 effort를 추상적으로 수치로 표현한 것**
- 시간(시간/일)이 아니라 **상대적 규모**를 뜻한다  
  예)
  - UI 수정 = 1포인트
  - 신규 API 개발 = 5포인트
  - 기능 간 데이터 연동 = 8포인트

> 단순히 ‘얼마 걸림?’이 아니라  
> **불확실성과 난도의 정도를 나타내는 개념**

---

## 🔄 Jira 실사용 프로세스 (애자일 기반)

### 1️⃣ 에픽 작성
- 프로젝트에서 구현해야 할 큰 단위 목표를 정의한다

### 2️⃣ 에픽을 쪼개서 백로그 작성
- 기능을 사용자 스토리/User Task로 나눈다  
  예)
  - “사용자는 NFC 태깅 시 주문을 조회할 수 있다”
  - “사용자는 로그인할 수 있다”

### 3️⃣ 스토리 포인트 배정
- 각 작업 난도를 팀이 합의해서 추정한다

### 4️⃣ 스프린트 계획(Planning)
- 이번 기간(1~2주)에 처리할 작업을 백로그에서 선택해 스프린트에 담는다

### 5️⃣ 보드에서 작업 진행
- 개발자가 수행할 작업을 가져가며 상태 변경
  - To Do → In Progress → Review → Done

### 6️⃣ 번다운 차트 체크
- 스프린트 기간 동안 남은 작업이 어떤 속도로 줄어드는지 확인

### 7️⃣ 회고(Review/Retrospective)
- 무엇이 잘 됐는지
- 무엇이 부족했는지
- 다음 스프린트 개선 방향을 논의한다

> Jira는 “계획 → 실행 → 추적 → 회고”라는 반복 사이클을 효율적으로 도와주는 도구

## 📉 번다운 차트란?

### ✔ 정의
스프린트 기간 동안 처리해야 남은 스토리 포인트를  
**시간 흐름에 따라 시각화한 그래프**

- Y축: 남아 있는 작업량
- X축: 시간(스프린트 기간)
- 이상적인 그래프: 상향 없이 꾸준히 내려가는 대각선

### ✔ 의미
- 계획 대비 실제 진행 속도를 비교할 수 있음
- 특정 시점에 **늦어지고 있는지 빨리 확인 가능**
- 막히는 작업이 무엇인지 드러나는 근거가 됨

### ✔ 오늘 느낀 점
> 번다운 차트는 단순한 그래프가 아니라  
> 팀이 같은 속도로 함께 나아가고 있는지 확인하는 **지표이자 경고등**이다.

- 작업량이 갑자기 멈추거나 줄지 않는다면
  - 이슈가 누적되고 있거나
  - 예상보다 난도가 높거나
  - 조율이 필요하다는 뜻
- 스프린트 후반에 몰아서 처리하면  
  → 그래프가 수직 하락하며  
  → **계획 실패를 의미**

👉 그래서 스프린트 기간 동안 주기적으로 체크하고  
👉 문제가 생기면 즉시 대응하는 것이 중요하다고 느꼈다

## ✨ 오늘 배운 핵심 요약

- 에픽은 “큰 방향”, 백로그는 “할 일 목록”
- 스프린트는 “짧은 실행 주기”
- 스토리 포인트는 “난도 기반 작업 추정 방식”
- Jira는 계획 → 실행 → 추적 → 회고를 연결하는 협업 도구
- 번다운 차트를 잘 관리하면  
  **일정 예측 가능 + 팀 일의 리듬 유지에 큰 도움**
